# Flashing

These firmware files are merged binaries.

## Use

Flash the merged `.bin` file at:

- Address: `0x0`

## Example file

- `firmwares/esp32-div/releases/esp32-div-cyd28-merged.bin`
- `firmwares/esp32-div/releases/esp32-div-cyd-c5-merged.bin`

Use your preferred ESP32 flashing tool to write the merged file to the device.

Make sure you choose the release file that matches your board variant.
